## MDP 设计
- **obs（20维）**：车位姿(x,y,cosθ,sinθ) + 速度(v,w) + 目标门相对坐标/朝向差 + 目标编号 + 下一门信息 + 其余两门概览，全部归一化
- **act（2维连续）**：线速度 × 角速度（一阶电机惯性）
- **奖励**：
  - 时间惩罚 −0.02
  - 进度奖励 2.0×(d前−d现)
  - 对准奖励 0.5×cos(对准角)×(v/vmax)×max(进度,0)×20 —— **速度+进度双门控**
  - 过正确门 +10（target+1），四门全过 +50
  - 出界 −5（终止），过错门 −5

## 踩坑记录（真实迭代过程）
1. **奖励钻空子 #1**：车学会原地朝门对准刷 +0.5/步 → 300 步拿 150 分不过门。
   修复：对准奖励乘速度门控 `(v/vmax)`。
2. **奖励钻空子 #2**：绕门盘旋仍能靠部分对准+微进度刷分、超时失败。
   修复：对准奖励再乘进度门控 `max(prog,0)×20`，只有"边走边靠近"才给。
3. **门布局死局**：随机门贴墙/重叠 → 分离迭代 + 每轮夹回边界 + 离起点≥2m。
4. **门被 jitter 推到贴墙**：法向指向墙外 → 穿门逼近点 clamp 进场内。
5. obs 相对坐标可超 1 → 输出前 clip 到 [-1,1]。

## 训练课程
阶段A（前 60%）：基准布局小扰动（jitter=2m）→ 阶段B（后 40%）：全场地随机。
门坐标进 obs → 训练时随机化即泛化，换布局无需重训。

## 最终效果（50 个全新随机布局）
- 成功率 45/50（90%），平均过门 3.62/4
- 失败模式：4 次撞墙、1 次超时、0 次过错门
- 学习曲线：阶段A 快速收敛 → 阶段B 初期回落（布局变难）→ 恢复并超越
